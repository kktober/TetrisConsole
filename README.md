# Тетрис — консольная игра на C#

Учебный проект по кейс-задаче № 4. Игра реализована на C# с использованием .NET 8 и консольного интерфейса.

## Возможности
- Игровое поле 10 × 20.
- Семь классических фигур, заданных двумерными матрицами `bool`.
- Движение фигур влево и вправо, ускоренное и автоматическое падение.
- Поворот фигур на 90 градусов.
- Проверка столкновений с границами и уже занятыми клетками.
- Фиксация фигуры на поле и удаление заполненных линий.
- Подсчёт очков и увеличение уровня/скорости.
- Проверка окончания игры при невозможности разместить новую фигуру.
- Возможность начать новую игру после завершения.

## Управление
- Стрелка влево или A — перемещение влево.
- Стрелка вправо или D — перемещение вправо.
- Стрелка вниз или S — ускоренное падение.
- Стрелка вверх, W или пробел — поворот.
- Esc — завершить текущую игру.

## Требования
- Windows 10/11.
- Visual Studio 2022 с компонентом разработки классических приложений .NET или .NET 8 SDK.

## Запуск
1. Откройте `TetrisConsole.csproj` в Visual Studio 2022.
2. Дождитесь восстановления зависимостей.
3. Выберите `Build → Build Solution`.
4. Запустите проект клавишей F5 или Ctrl+F5.

Либо из терминала в папке проекта выполните:
```bash
dotnet run
```

## Структура проекта
- `Program.cs` — основной цикл игры, логика фигур, поля, управления и отрисовки.
- `TetrisConsole.csproj` — настройки проекта.
